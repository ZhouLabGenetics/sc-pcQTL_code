# Module 11 - Manuscript figures and tables

This module assembles the final figures and supplementary tables from outputs
generated by modules 01-10 and module 12.

## Scripts

- `figures/compose_fig2_simulation.R`: simulation figure.
- `figures/build_cluster_landscape_tables.R` and
  `figures/compose_fig3_cluster_and_coloc.R`: cluster and colocalization figure.
- `figures/build_gimap_hurdle_matrix.R` and
  `figures/compose_gimap_main_figure.R`: GIMAP main figure.
- `figures/compose_supp_gene_effects.R`: PIP-weighted gene-effect figure.
- `figures/compose_supp_gimap_followup.R`: GIMAP follow-up figure.
- `figures/plot_supp_cross_mappability.R`: cross-mappability figure.
- `figures/plot_exploratory_ATP13A3_RPL35A.R`,
  `figures/plot_exploratory_MIF_MTFP1.R`, and
  `figures/plot_exploratory_ATG7_HACL1.R`: independent exploratory `B_IN`
  hurdle-versus-pseudobulk panels for Supplementary Figure S1. They are
  plot-only, use fixed diagnostic annotations, and are not inputs to the
  primary workflow.
- `figures/build_pcqtl_discovery_by_celltype.R`: cell-type pcQTL counts for
  Figure 3.
- `tables/make_supplementary_tables.py`: supplementary tables and
  machine-readable data files.

## Required paths

Set `SC_PCQTL_MANUSCRIPT_ROOT`, `SC_PCQTL_WORKFLOW_ROOT`,
`SC_PCQTL_FORMAL_COLOC_ROOT`, `SC_PCQTL_CROSSMAP_ROOT`, and
`SC_PCQTL_JOINT_SCORE_COMPARISON_ROOT`. GIMAP scripts additionally require the
module-10 locus work root, the CD8_NC count matrix, and the targeted SMR output
paths. The exploratory pair panels use `COQTL_RAW_COUNTS_FILE`. Optional output
overrides are documented in `config/example.env`.

The scripts write figures under `SC_PCQTL_MANUSCRIPT_ROOT/figures` and tables
under `SC_PCQTL_MANUSCRIPT_ROOT/supplementary`.
